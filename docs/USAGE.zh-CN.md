**显示标题：** 普通便签、关联章节及每日便签在顶部和任务栏显示当前 Markdown 文件名（不含 `.md`）。重命名后立即更新，编辑期间也会同步。YAML 的 `title` 保留为元数据；在属性中修改它不会更改文件名或显示标题。关联章节名称保留在标题提示中，保留昨日每日笔记时使用单独提示。

**重命名文件：** 使用 `… → 重命名文件…` 或双击便签标题。输入框全选当前名称（不含扩展名），Enter确认，Esc取消。保留 `.md` 扩展名、目录、YAML `title`、位置、尺寸、颜色及标题筛选，并更新引用同一文件的其他便签及最近关闭记录。仍可拖动标题移动窗口。支持普通便签和固定标题便签，不支持每日便签。更名前先保存正文；如果其他便签有同一文件的未保存更改，请先保存。拒绝重复名称、无效名称及仅大小写变化（可先改为其他名称）。Obsidian CLI模式遵循Obsidian的链接更新设置；本地模式不修改其他笔记中的链接。失败时请检查原路径和目标路径，若已移动请重新打开目标文件。恢复记录保留在应用数据目录的 `note-renames` 中。

任务正文后输入空格显示候选，首项 **⏎** 上Enter继续检查列表。↓选择后Enter或点击插入字段，Tab缩进；日期字段则默认选中第一个日期。参见[详细行为与限制](TASK-EDITING.md#简体中文)。

任务关键字／日期补全、Enter继续检查列表及Tasks原生复选框行为，请参见[任务输入指南](TASK-EDITING.md#简体中文)。

通过 **…**、通知区域或任务栏菜单的 **管理便签文件夹…**，查看正文／YAML 并重新打开已关闭便签。参见 [查询复选框与文件夹列表](QUERY-EDITING-AND-BROWSER.md#简体中文)。

v0.0.8支持通过 CLI 将 Dataview LIST／TABLE／TASK 与 Tasks 和普通 Markdown 同时显示。请在目标仓库启用 Dataview。结果约每 30 秒刷新，已验证原任务的复选框可直接更新原笔记。不支持 DataviewJS、内联表达式或 CALENDAR。参见 [Dataview 设置和限制](DATAVIEW.md#简体中文)。

## 显示语言

## 编辑与保存

在**设置 → 切换复选框的快捷键**中设置按键（例如`Ctrl+Enter`）并保存，即可在编辑时切换光标所在行的复选框。默认未设置，可清除。支持撤销，通过正常保存流程写入。参见[按键设置、支持的行和限制](TASK-EDITING.md#简体中文)。

| 控件 | 操作 |
| --- | --- |
| `… → 创建与打开 → 新建便签` | 新建便签 |
| `… → 编辑` / `Ctrl+E` | 编辑 Markdown 源文本 |
| `保存` / `Ctrl+S` / `Esc` | 保存文件并返回阅读模式 |
| `… → 重新加载` | 重新读取源文件；存在未保存修改时会确认 |
| `…` | 打开属性、获取日程、打开已有文件、关联标题部分、设置或退出 |
| `… → 关闭便签` | 关闭这张便签，不删除 Markdown 文件 |
| `… → 退出应用（保存布局）`，或通知区域的 `退出` | 退出应用 |

在设置的 **开始编辑正文的操作 → 单击／双击** 中选择通过正文或空白处进入编辑的方式。包括已有设置在内，默认仍为单击；保存设置后立即应用于已打开的便签。光标移到点击处对应的 Markdown 源文本位置，并滚动显示该行。点击 Tasks／Dataview 生成结果时会移到原查询。复选框、链接和滚动条保持原有操作。再次点击编辑会保留输入，保存后返回阅读模式。

`Esc`无需确认即可保存并结束编辑，不受失去焦点时保存设置影响。未修改时直接返回阅读；保存失败或冲突时保留草稿及编辑界面。补全候选打开时，首次`Esc`关闭候选，下次`Esc`保存并结束编辑。输入法组合输入及编辑器右键菜单优先使用各自的 Esc 操作。

离开编辑器时，仅在文本有修改的情况下询问。

| 选择 | 结果 |
| --- | --- |
| 是 | 保存 |
| 否 | 放弃修改并重新加载 |
| 取消 | 保留输入并继续编辑 |

设置中的 `编辑器失去焦点时自动保存` 可跳过此确认，默认关闭。自动保存仍备份并检测冲突；失败时保留输入。右键菜单不会触发确认，关闭便签或退出时仍检查未保存的修改。

打开“…”菜单时暂缓失焦保存及确认。关闭菜单后，若焦点仍在编辑器之外，则恢复正常处理。通过自动保存、保存按钮、Ctrl+S或Esc触发的CLI编辑保存不会阻塞界面。写入期间暂缓该便签的编辑、关闭及设置更改；失败时保留草稿。关闭时的保存确认、元数据保存和新建便签的CLI操作仍为同步处理。

## 显示与窗口

拖动便签顶部可移动，拖动边缘或右下角可调整大小。`○ / ●` 切换置顶。便签没有标准标题栏，通常不显示在任务栏中；应用驻留在通知区域。

### 批量重新显示最近关闭的便签

如果误选 Windows 任务栏的 **关闭所有窗口**，可从通知区域图标、任务栏菜单或便签的 **…** 菜单选择 **重新显示最近关闭的便签**。最近一组便签会恢复位置、尺寸、置顶、缩放、关联标题及标题筛选。已打开的便签不会重复创建。原有的 **全部显示** 用于显示仍然打开的便签或取消其最小化。

上一次关闭完成后两秒内收到的下一次关闭请求属于同一组。手动快速关闭也会合并，间隔较长则开始新组。打开便签、恢复一组或保存设置会结束当前分组。设置只保留最近一组，重启后仍可恢复；恢复成功的记录会移除。**退出** 仍保存当前窗口布局，不覆盖该历史记录。

取消关闭的便签不加入历史。恢复的是显示设置和已保存文件，不包括丢弃的未保存编辑或已删除文件。找不到源文件时会在便签中显示读取错误。切换笔记读取方式或 Obsidian 连接时只清除该 Vault 的历史，保留其他 Vault，避免从错误来源打开笔记。若所有便签均已关闭且存在历史，启动后应用会驻留通知区域，可从那里恢复。

### 任务栏与菜单

设置中的 `在任务栏显示便签图标` 控制任务栏图标，默认关闭。应用到所有便签并在重启后保留；通知区域图标仍可使用。

右键点击任务栏图标，可使用与通知区域菜单相同的十项操作：新建便签、打开Markdown、浏览便签文件夹、关联笔记的一部分、显示每日笔记、显示全部、重新显示最近关闭的便签、临时置顶、设置和退出。Windows以跳转列表任务的形式显示这些操作，同时保留系统的固定和关闭选项。“显示全部”也会恢复最小化的便签。操作转交给正在运行的应用，退出时仍会确认未保存的修改。应用停止时选择任务会启动并执行，但单独选择“退出”不会开始新会话。更新后重新启动一次应用即可注册菜单。使用独立数据的 `--data-dir` 测试模式不会注册或更改任务栏菜单。

### 临时置顶

`Alt + Z` 是固定的全局快捷键，在操作其他应用时也可使用。仅在便签应用运行期间有效，长按不会连续触发。与其他应用的注册冲突会显示通知。请解决冲突并重新启动，或使用以下菜单操作。

从通知区域或 `…` 菜单选择 `将全部便签置顶（10秒）`，恢复最小化的便签并将全部便签置顶10秒。再次执行可延长时间。

结束后恢复各便签的固定设置，但不恢复原来的窗口叠放顺序。临时置顶不保存；期间点击 `○ / ●` 会立即为该便签应用新的固定设置。

### 按钮显示

标题和控件共用一行，通常显示标题筛选、置顶和更多。编辑、重新加载、新建和关闭移到更多菜单，保存按钮仅在编辑时显示。更多菜单中“显示与属性 → 显示/隐藏详细信息”可切换标签和状态，标题提示也提供这些信息。保存/读取成功提示四秒后隐藏，错误保持可见。

启用 `鼠标悬停在标题上时显示按钮` 后，可通过悬停显示控件，正文位置不变。编辑时始终提供保存操作。关闭此设置可恢复始终显示。

用左端手柄移动便签，或按 `F6` → `Tab` 操作按钮。标题内有键盘焦点或更多菜单打开时也会显示按钮。设置立即应用到全部便签并在重启后保留。

### 缩放与布局

通过 `… → 显示与属性 → 显示缩放` 设置50～200%（默认100%，每次增减10个百分点）。阅读时也可用 `Ctrl＋滚轮`、`Ctrl++`／`Ctrl+-`，`Ctrl+0` 重置。

正文、日程和每日笔记提示按相同比例缩放；标题、控件和编辑器不变。倍率按便签保存，重新加载和重启后恢复，不修改源 Markdown 或未保存的输入。

移动或退出时会记录便签位置、大小和置顶状态，下次启动时恢复。支持多显示器、负屏幕坐标和 PerMonitorV2 DPI。原显示器断开后，便签会移回可用屏幕。退出前会确认未保存的修改。

## 文件存储与 Obsidian

确定仓库（CLI）或本地基准目录后，点击**选择便签保存文件夹…**。从列表选择或输入新的相对路径，点击**确定**后选择是否迁移已有应用便签。**是**迁移，**否**仅更改新便签位置，**取消**不做更改。选择保持为草稿，最后在设置中 **保存并关闭** 后应用（仅主注册）。范围、回滚及恢复请参见[文件夹选择与迁移指南](STICKY-FOLDERS.md#简体中文)。

显式便签目录优先于Obsidian的一般新笔记位置。未选择时，CLI保持Obsidian默认位置，本地模式保留已有目录（初始为`Documents/StickyNotesData`）。日记设置独立。

### 属性与 Bases

笔记是普通 UTF-8 `.md` 文件，可包含以下属性：

```yaml
---
type: sticky
id: unique-note-id
title: 购物清单
tags:
  - sticky
  - personal/shopping
status: active
color: yellow
created: 2026-10-05T09:00:00+09:00
updated: 2026-10-05T09:00:00+09:00
---
```

使用 `… → 显示与属性 → 标签、标题、状态和颜色`（标签、标题、状态、颜色）编辑属性。支持 `yellow / green / blue / pink / gray`。`status` 可填写 `active / done / archived` 等；它仅用于整理，不会自动隐藏或删除便签。

把 [StickyNotes.base](../examples/StickyNotes.base) 复制到仓库，可列出 `type: sticky` 的笔记。如需在其他 Bases 中排除便签，可用 `type != "sticky"`，或用 `!file.inFolder("Sticky Notes")` 排除文件夹。

布局与授权数据保存在仓库之外的 `%LOCALAPPDATA%/StickyNotes`。应用在 CLI 模式约每30秒、本地模式约每2秒检查一次文件外部修改；编辑期间会提示冲突，不会自动替换输入。

参考：[Obsidian Properties](https://obsidian.md/help/properties)、[Bases 语法](https://obsidian.md/help/bases/syntax)。

## 每日笔记

1. CLI 模式下配置 Obsidian 核心 Daily notes 插件，并在便签设置中确认文件夹、格式、模板及今日路径。本地模式下设置文件夹及带日期标签的正则表达式，确认匹配文件名并点击 `保存并关闭`。
2. 选择 `… → 创建与打开 → 显示每日笔记…`（显示每日笔记），从默认 Vault 开始，可切换 Vault 并加载今天的文件，然后选择标题。无需输入绝对路径或切换每日模式。
3. 在共用的标题选择框中选择已有标题，或输入不带 `#` 的新名称。留空表示整个正文。
4. 点击 `显示`。新名称会在备份后以 `## 标题` 追加到原文件末尾。仅输入或取消不会写入。勾选任务会更新源文件中的对应行。

### 文件名规则

本小节仅适用于本地模式。CLI 模式使用 Obsidian 设置解析今天、昨天，不扫描仓库或匹配正则表达式；日期格式在 Obsidian 中设置。下述等待及保留选项适用于两种模式。

每日笔记文件名仅使用**日期标签 + 正则表达式**，不再有日期格式模式或模式复选框。标签是命名组 `year`、`month`、`day`。对于 `2026-10-05(月).md` 等文件名，选择对应文件夹并使用：

```regex
(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})(?:\([^)]+\))?\.md
```

空白输入会自动填入该默认表达式。`插入带日期标签的默认示例`按钮会先询问，再替换整个输入；选择**否**会保留已有内容。打开设置时不询问。修改会更新匹配结果，保存设置后才持久化。

停止输入约 300 毫秒后，设置页会按尚未保存的文件夹和表达式显示今天的匹配文件名或错误。更改文件夹也会刷新。搜索在后台运行，过期结果会被丢弃。

<details>
<summary>匹配规则、旧格式与搜索限制</summary>

每个必需标签必须捕获一个数字日期部分，只有捕获日期等于本地目标日期（通常为今天，保留模式下为昨天）的文件才会被选中。匹配忽略大小写，覆盖**包含 `.md` 扩展名的完整相对路径**，不会自动补扩展名。子文件夹用 `/` 分隔；如果选择父目录，可在表达式前加 `Diary/`。此示例不会匹配其他日期或 `WeeklyTasksLog-…` 等前缀文件。

已有正则表达式保持不变。加载旧设置时，会转换 `yyyy-MM-dd`、`yyyy/MM/yyyy-MM-dd`，以及分别带 `(ddd)`、`(dddd)` 后缀的格式。其他自定义日期格式保留为文本，需在设置中手动修正，不再作为日期格式执行。转换不会移动文件或文件夹。

搜索包含子文件夹，跳过符号链接和目录联接；所选根目录的路径也不能包含它们。今日无匹配时按下述等待／保留设置处理；多个匹配会报错。不创建文件、不任意选择。搜索错误时保留未保存的编辑。保存设置时会拒绝无效表达式。表达式最多 4,096 字符，单次匹配限时 100 毫秒；每次搜索在条目之间检查 10,000 项和一秒的上限。文件系统访问本身可能更慢，建议直接选择每日笔记目录，缩小搜索范围。

</details>

### 今日笔记不存在时

日期变化后切换到今天的文件。若今日笔记尚未创建，已有每日便签的正文区域会提示：在 Obsidian 中创建今日笔记后将自动显示，也可通过设置继续显示昨天的笔记。应用在 CLI 模式约每30秒、本地模式约每2秒检查一次。

设置中的 `今日笔记尚未创建时`提供三种选择：

- **显示等待提示（默认）**：今日笔记不存在时显示说明。
- **1. 显示昨天的笔记，直到今日笔记创建**：检测到今日文件后自动切换。
- **2. 显示昨天的笔记，直到重新加载**：因今日笔记不存在而显示昨天时，即使今日文件随后创建，也保留昨天，直到点击 `重新加载`。

<details>
<summary>保留与重新加载补充</summary>

昨天也不存在时显示等待提示，不查找更早日期。两种保留模式下，重新加载都会检查今天；若仍不存在，当天继续等待，不再返回昨天。保留状态仅在便签打开期间有效，重启时若今日笔记已存在则显示今天；设置选项本身会保存。显示昨天时会标明日期和说明，编辑及任务勾选保存到该日期的源文件。编辑期间暂停自动切换并保留未保存输入。文件夹或正则表达式错误、多个匹配、缺少标题仍显示错误。应用不自动创建文件；只有在选择窗口输入新标题并点击显示时才追加标题。首次添加每日便签需要已有今日文件。

</details>

## 标题选择与预览

固定笔记使用独立菜单 `… → 创建与打开 → 显示笔记的一部分…`（将笔记的一部分显示为便签）。点击 `选择文件夹…` 先选文件夹再选 Markdown，或直接使用 `选择 Markdown 文件…`。没有手动绝对路径输入和每日模式开关。两种窗口使用相同的标题选择组件，都可选已有标题、输入新名称或留空显示正文。通知区域菜单也提供这两个入口；`重新加载` 可刷新标题列表。

固定笔记和每日笔记选择窗口的最后一项是只读内容预览。加载、重新加载文件，选择或输入标题时，会更新所选范围的 Markdown，最多 4,000 字符。空标题预览整个正文，新标题显示待追加提示。预览不写入文件。

标题部分从所选标题之后开始，到下一个相同或更高级别标题之前结束，包含子标题。其他部分和 YAML 前置元数据保持不变。重复标题会阻止编辑，围栏代码中的标题被忽略。请使用 `#` 风格的 ATX 标题。

点击显示前若源文件被外部修改，会要求重新加载而不覆盖。每日笔记目标变化（包括跨越午夜）时也一样。追加保留原内容、换行和 UTF-8 BOM。重复标题会导致歧义，未闭合代码围栏中的追加会被隐藏；这些情况均会被拒绝。

## Markdown 支持与数据保护

- 显示标题、粗体、斜体、删除线、有序和无序列表、清单、引用、代码、表格和链接。
- HTML 作为文字显示，不执行；图片目前显示替代文字。
- 不支持 Obsidian `[[wikilinks]]`、嵌入、数学公式渲染或专用 callout 样式；原文本保留。v0.0.8通过 CLI 支持 Dataview LIST／TABLE／TASK，不支持 DataviewJS、内联表达式或 CALENDAR。参见 [Dataview](DATAVIEW.md#简体中文)。
- 读取有或无 BOM 的 UTF-8，并保持原选择；正文编辑遵循文件现有换行。
- 属性编辑会重新序列化 YAML，注释或格式可能变化；未知属性值及正文保留。
- 写入前检查整个文件的哈希。外部修改会阻止过期写入；重新加载前可复制输入或另存。
- 写入前内容备份到 `%LOCALAPPDATA%/StickyNotes/backups`，文件名包含日期和 GUID，可手动恢复，不会自动删除。
- 写入时独占文件，失败时尝试恢复原内容。请同时保留常规仓库备份，以应对断电等情况。

## 标题筛选

点击 **标题** 搜索并选择章节。单选显示标题名，多选显示数量，使用淡蓝色背景。选择即时生效并按便签保存。**显示全部** 清除筛选，Esc 关闭。面板对齐便签右侧，平时显示短名称，搜索或同名时显示父级路径。父章节包含子章节，按原文顺序显示且不重复。

仅支持文档顶层的 Markdown 标题（ATX 和 Setext），不包含引用、列表或代码块中的标题。同名标题通过父级路径区分，重复路径不能选择。重命名、删除或移动标题可能导致目标失效，此时显示提示，不会自动显示其他内容。请清除筛选后重新选择。

筛选仅影响显示。编辑时显示筛选前的正文，并跳转到第一个选定标题。已有标题链接的便签仍限于其链接章节。任务操作保留原文行号；隐藏的 Tasks、Dataview 和日历内容不参与显示。正文保留标题。

### 紧凑正文显示

正文使用字号14、行高21，紧凑列表项间距为2，带空行的列表额外增加5。任务省略多余圆点，折行与正文起点对齐。子列表缩进18，表格段落不添加额外边距。标题字号为20/18/16，背景采用淡色。这些数值为100%缩放时的WPF逻辑单位。保留现有普通换行行为、源文本、任务更新及编辑位置。

复选框使用 Windows 主题的自然宽度，正文折行按实测宽度及文字间隔对齐。
