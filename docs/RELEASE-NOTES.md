# Markdown Sticky Notes v0.0.5

## 日本語

Windows 10 / 11（x64）向け。アプリUIが日本語・英語・簡体字中国語に対応しました。

- **表示言語の選択**：設定から「Windowsに合わせる／日本語／English／简体中文」を選択。保存後、次回起動時に反映します。既定はWindowsの表示言語に合わせ、中国語は簡体字中国語、対応外の言語は英語で表示します。
- **画面全体を翻訳**：メニュー・設定・ダイアログ・Google連携ガイド・入力補完の説明・アプリのエラー・新規ノートの雛形に対応。既存ノートの本文・タイトル・見出し・タグやGoogleの予定内容は変更しません。
- **3言語の資料を更新**：言語設定の手順と制限を追記し、翻訳ファイルを配布物に同梱しました。

### インストール・更新

アプリを終了し、Assetsの **StickyNotes-win-x64.zip** を別フォルダへ展開して **Install.cmd** を実行してください。ノート・設定・バックアップは保持されます。直接 `StickyNotes.exe` を起動する場合も、同梱ファイル全体を保持してください。

管理者権限や.NETの追加インストールは不要です。アプリは未署名です。SHA256は同梱の `.zip.sha256` で確認できます。Windows標準ダイアログのボタン・外部ページ・OSやライブラリ由来のエラーは別の言語で表示される場合があります。

Google連携は任意で、利用者自身のOAuth設定が必要です。実Googleアカウントでの接続・更新は自動テストの対象外です。

## English

For Windows 10 / 11 (x64). The app UI now supports Japanese, English, and Simplified Chinese.

- **Choose a display language:** In Settings, select Use Windows language / 日本語 / English / 简体中文. Save and restart to apply. The default follows Windows: Chinese uses Simplified Chinese; unsupported languages use English.
- **Translated interface:** Menus, settings, dialogs, Google setup guidance, completion help, app errors, and new-note templates are translated. Existing note text, titles, headings, tags, and Google event content stay unchanged.
- **Updated documentation:** All three languages include language settings and limitations. Translation files are included in the package.

### Installation and updates

Exit the app, extract **StickyNotes-win-x64.zip** from Assets into a separate folder, and run **Install.cmd**. Notes, settings, and backups are retained. For portable use, run `StickyNotes.exe` and keep all accompanying files.

No administrator privileges or separate .NET installation are required. The app is unsigned. Verify the SHA256 using the accompanying `.zip.sha256` file. Windows dialog buttons, external pages, and system/library errors may use another language.

Google integration is optional and requires your own OAuth setup. Automated tests do not connect to or update a real Google account.

## 简体中文

支持 Windows 10 / 11（x64）。应用界面现已支持日语、英语和简体中文。

- **选择显示语言**：在设置中选择“跟随 Windows／日本語／English／简体中文”，保存后重启生效。默认跟随 Windows；中文使用简体中文，其他不支持的语言使用英语。
- **翻译应用界面**：菜单、设置、对话框、Google 配置指南、补全说明、应用错误提示和新便签模板均已翻译。已有笔记的正文、名称、标题、标签及 Google 日程内容保持不变。
- **更新三种语言文档**：增加语言设置方法及限制，分发包附带翻译文件。

### 安装与更新

退出应用，将 Assets 中的 **StickyNotes-win-x64.zip** 解压到另一文件夹，运行 **Install.cmd**。笔记、设置和备份会保留。免安装使用时运行 `StickyNotes.exe`，并保留全部附带文件。

无需管理员权限或另装 .NET。应用未签名，可使用附带的 `.zip.sha256` 文件验证 SHA256。Windows 对话框按钮、外部网页和系统或库的错误信息可能使用其他语言。

Google 集成为可选功能，需要自行配置 OAuth。自动测试不连接或修改真实 Google 账号。
