Windows 10 / 11（x64）向けMarkdown付箋アプリです。

変更履歴は同梱の `CHANGELOG.ja.md`（日本語）または `CHANGELOG.md`（英語）にあります。GitHubでも [日本語](https://github.com/AvocadoWasabi/StickyNotes/blob/main/CHANGELOG.ja.md) / [English](https://github.com/AvocadoWasabi/StickyNotes/blob/main/CHANGELOG.md) を参照できます。

- `StickyNotes-win-x64.zip` をダウンロードし、すべて展開して `Install.cmd` を実行してください。
- .NETの追加インストール・管理者権限は不要です。
- インストールせず、展開先の `StickyNotes.exe` から起動することもできます。
- 更新前に通知領域のメニューからアプリを終了してください。

使い方とGoogle Calendar連携の設定は同梱の `README.ja.md`（日本語）または `README.md`（英語）、導入・更新・削除の詳細は `docs/INSTALL.md` を参照してください。
