# Markdown Sticky Notes v0.0.1

## 日本語

Windows 10 / 11（x64）向けの初回公開版です。通常のMarkdownファイルをデスクトップの付箋として表示・編集できます。

主な機能:

- 複数の付箋、サイズ変更、最前面表示、配置の復元
- Markdown表示・編集、チェックリスト、タグ・タイトル・状態・色の管理
- Obsidian Vault連携、指定見出しの表示・編集、デイリーノートの日付切り替え
- Google Calendarの予定表示・件名と説明の編集（任意・要OAuth設定）
- 外部変更の検出、競合時の上書き防止、書込み前のバックアップ

インストール:

1. Assetsの **StickyNotes-win-x64.zip** をダウンロードします。
2. ZIPを「すべて展開」し、**Install.cmd** をダブルクリックします。
3. スタートメニューの **Markdown Sticky Notes** から起動します。

管理者権限や.NETの追加インストールは不要です。インストールせず、展開先の `StickyNotes.exe` から起動することもできます。EXE以外の同梱ファイルも保持してください。更新前は通知領域の「終了」でアプリを終了します。

アプリは未署名で、画面・操作ボタンは日本語です。Google Calendarを使わなければ認証は不要です。チェックサムは `StickyNotes-win-x64.zip.sha256` に記載しています。

## English

First public release for **Windows 10 / 11 (x64)**. Display and edit ordinary Markdown files as desktop sticky notes.

Features:

- Multiple resizable notes, always-on-top mode, and restored window positions
- Markdown viewing and editing, checklists, tags, titles, status, and colors
- Obsidian vault integration, linked heading sections, and daily note switching
- Optional Google Calendar event viewing and title/description editing with your own OAuth configuration
- External-change detection, conflict protection, and pre-write backups

Installation:

1. Download **StickyNotes-win-x64.zip** under Assets.
2. Extract the entire ZIP and double-click **Install.cmd**.
3. Open **Markdown Sticky Notes** from the Start menu.

No administrator privileges or separate .NET installation are required. For portable use, run `StickyNotes.exe` from the extracted folder and keep all accompanying files. Exit the app from its notification-area menu before updating.

The app is unsigned and its controls are currently in Japanese. Google sign-in is unnecessary unless you use Calendar integration. The SHA256 checksum is provided in `StickyNotes-win-x64.zip.sha256`.
