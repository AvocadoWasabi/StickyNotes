# Установка и настройка

[README](../README.ru.md) · [Usage (English)](USAGE.en.md)

## 1. Установка

Для Windows 10 / 11 (x64). Права администратора и отдельная установка .NET не требуются.

1. Скачайте **StickyNotes-win-x64.zip** из [Releases](https://github.com/AvocadoWasabi/StickyNotes/releases/latest). `Source code` — архив исходного кода.
2. Полностью распакуйте ZIP и запустите `Install.cmd`.
3. Запустите **Markdown Sticky Notes** через меню «Пуск».

Можно запускать `StickyNotes.exe` прямо из распакованной папки, сохранив все соседние файлы. Приложение не подписано, поэтому Windows может запросить подтверждение. Автозапуск не регистрируется.

Это руководство для v0.0.11. Несколько хранилищ, Tasks 8.2.2 и девять языков интерфейса описаны в [журнале изменений (на английском)](../CHANGELOG.md#v0-0-11).

## 2. Место хранения и способ подключения

### Использование Obsidian CLI (по умолчанию)

1. Включите в Obsidian **Settings → General → Command line interface** и следуйте инструкциям регистрации. Если пункта нет, проверьте требования к обновлению установщика в [официальном руководстве CLI](https://obsidian.md/help/cli).
2. Откройте нужное хранилище и оставьте Obsidian запущенным.
3. В общих настройках приложения проверьте абсолютный путь к `Obsidian.com`, обычно `C:\Program Files\Obsidian\Obsidian.com`. Исправьте путь, если Obsidian установлен в другом месте.
4. В разделе хранилищ и ежедневных заметок включите CLI для нужной записи, введите имя/ID хранилища и нажмите кнопку получения папки через CLI. Пустое поле использует выбор Obsidian по умолчанию; одного ввода недостаточно для получения папки.
5. Проверьте полученное хранилище и настройки ежедневных заметок, выберите папку сохранения заметок и сохраните настройки.

При смене папки «Да» также переносит существующие заметки, созданные приложением; «Нет» меняет только место будущего сохранения; «Отмена» отменяет смену. [Область переноса и восстановление (на английском)](STICKY-FOLDERS.md#english). При ошибке CLI автоматического перехода к локальному чтению нет.

### Использование локальных файлов

Отключите Obsidian CLI в настройках, выберите локальную базовую папку и папку заметок, затем сохраните. Начальная папка — `Documents/StickyNotesData`. Запросы Tasks/Dataview недоступны. Локальные ежедневные заметки настраиваются через папку и регулярное выражение с захватом даты. [Примеры (на английском)](USAGE.en.md#daily).

## 3. Необязательные интеграции

| Интеграция | В Obsidian / Google | В Sticky Notes |
| --- | --- | --- |
| Ежедневные заметки | Включить основной плагин Daily notes, задать папку и формат даты, создать сегодняшнюю заметку | В меню создания/открытия выбрать ежедневную заметку и заголовок; пустое поле показывает всю заметку |
| Tasks | Включить в нужном хранилище; v0.0.11 требует стабильную версию 8.2.2 или новее | Открыть заметку с блоком `tasks`. [Настройка и ограничения (на английском)](TASKS-CLI-PREVIEW.md#english) |
| Dataview | Включить в нужном хранилище | Показать LIST / TABLE / TASK в блоках `dataview`. [Настройка и ограничения (на английском)](DATAVIEW.md#english) |
| Google | Настроить Calendar API, Tasks API и OAuth для настольного приложения в собственном Cloud-проекте | Импортировать JSON, авторизоваться и записать `@calendar today` отдельным абзацем. [Подключение (на английском)](GOOGLE-CALENDAR.en.md#setup) |

Обычные флажки Markdown не требуют Tasks. Подсказки задач по умолчанию работают в автоматическом режиме и без Tasks отключены, пока не будут включены вручную. Если интеграция Google не используется, авторизация Google не нужна.

## 4. Создание и редактирование заметок

Создайте или откройте Markdown через меню создания/открытия в `…`. Щёлкните текст или нажмите `Ctrl+E` для редактирования; `Ctrl+S` / `Esc` сохраняет. Для первого подключения ежедневной заметки нужен сегодняшний файл; автоматически он не создаётся. Выберите язык в настройках, сохраните и перезапустите приложение. Интерфейс v0.0.11 поддерживает девять языков, перечисленных в README.

## Устранение неполадок

| Симптом | Что проверить |
| --- | --- |
| CLI не подключается | Запущен ли Obsidian, включён ли CLI, верны ли абсолютный путь к `Obsidian.com` и имя/ID хранилища; повторить получение папки |
| Нет сегодняшней заметки | Настройки основного плагина Daily notes и сегодняшний файл; настройки других плагинов ежедневных заметок автоматически не определяются |
| Tasks требует обновление | Обновить Tasks в нужном хранилище до 8.2.2 или новее, затем обновить Tasks / Dataview в заметке |
| Конфликт сохранения | Сохранить черновик и перечитать файл; приложение предотвращает перезапись устаревшим содержимым |
| Ошибка авторизации Google | Проверить API, OAuth, тестовых пользователей и разрешения по [руководству (на английском)](GOOGLE-CALENDAR.en.md) |

## Обновление, данные и удаление

Для обновления сохраните правки, завершите приложение через область уведомлений, распакуйте новый ZIP в другую папку и запустите `Install.cmd`. Заметки, настройки и копии хранятся отдельно от программы. Если в настройках v0.0.6 или старше нет выбора CLI, теперь CLI включается: для локального режима отключите и сохраните; файлы автоматически не переносятся. Свои шаблоны дат v0.0.1 может потребоваться исправить.

| Данные | Расположение |
| --- | --- |
| Программа | %LOCALAPPDATA%/Programs/MarkdownStickyNotes |
| Настройки и учётные данные | %LOCALAPPDATA%/StickyNotes |
| Копии перед записью | %LOCALAPPDATA%/StickyNotes/backups |
| Заметки | Выбранное хранилище/папка |

Для удаления завершите приложение, удалите папку установки и ярлык меню «Пуск». Заметки, настройки и резервные копии сохранятся; проверьте их перед отдельным удалением.
