# Установка и настройка

[README](../README.ru.md) · [Usage (English)](USAGE.en.md)

## 1. Начало работы

Windows 10 / 11 (x64). .NET входит в ZIP; права администратора не нужны. В новых настройках CLI включён по умолчанию. Для локальных файлов отключите его. Отдельный плагин Sticky Notes для Obsidian не требуется.

1. Скачайте `StickyNotes-win-x64.zip` из Releases, полностью распакуйте и запустите `Install.cmd`.
2. Откройте Obsidian, включите CLI и оставьте нужное хранилище открытым.
3. В настройках приложения проверьте абсолютный путь к `Obsidian.com` и имя/ID хранилища. Получите папку через CLI, выберите папку заметок и сохраните настройки.
4. В меню `…` создайте/откройте заметку либо подключите раздел или ежедневную заметку.

[Releases](https://github.com/AvocadoWasabi/StickyNotes/releases/latest)

Можно запускать `StickyNotes.exe` прямо из распакованной папки, сохранив все соседние файлы. Приложение не подписано, поэтому Windows может запросить подтверждение. Автозапуск не регистрируется.

Документация описывает текущую версию в разработке. Отличия от опубликованного ZIP указаны в Unreleased. [Unreleased](../CHANGELOG.md#unreleased)

## 2. Obsidian или локальные файлы

Включите CLI в Obsidian и выполните инструкции регистрации. Если настройки нет, проверьте требования к установщику в официальном руководстве CLI. В настройках приложения проверьте абсолютный путь (обычно `C:\Program Files\Obsidian\Obsidian.com`). В разделе хранилищ и ежедневных заметок включите CLI для записи, введите имя/ID и нажмите кнопку получения папки. Пустое поле использует выбор Obsidian по умолчанию; один ввод текста ничего не загружает. Проверьте полученные папки, выберите папку заметок и сохраните.

[Obsidian CLI](https://obsidian.md/help/cli)

Без Obsidian отключите CLI, выберите локальную базовую папку и папку заметок, затем сохраните. Начальная папка — `Documents/StickyNotesData`. Запросы Tasks/Dataview недоступны. Для локальных ежедневных заметок можно задать папку и регулярное выражение с группами даты.

При смене папки Да переносит существующие заметки, созданные приложением; Нет меняет только место будущего сохранения; Отмена прекращает смену. При ошибке CLI автоматического перехода к локальному чтению нет.

[Storage (English)](STICKY-FOLDERS.md#english) · [Daily notes (English)](USAGE.en.md#daily)

## 3. Необязательные интеграции

Daily notes: задайте папку/формат даты в Obsidian, создайте сегодняшний файл и выберите отображение ежедневной заметки в меню создания/открытия. Без выбранного заголовка отображается весь файл. Включите Tasks 8.2.2+ или Dataview в нужном хранилище и откройте блоки `tasks`/`dataview`. Обычным флажкам Tasks не нужен. Подсказки по умолчанию автоматические и без Tasks выключены, если не включены вручную. Для Google настройте свои API и OAuth для настольного приложения, импортируйте JSON, авторизуйтесь и добавьте `@calendar today` отдельным абзацем. Без интеграции Google авторизация не нужна.

[Tasks (English)](TASKS-CLI-PREVIEW.md#english) · [Dataview (English)](DATAVIEW.md#english) · [Google (English)](GOOGLE-CALENDAR.en.md#setup)

## 4. Управление

Щёлкните текст (один/два щелчка настраиваются) или нажмите `Ctrl+E` для правки; `Ctrl+S` / `Esc` сохраняет. Первое Esc закрывает открытые подсказки. Отмечайте флажки в режиме чтения. `○ / ●` закрепляет окно. Закрывайте заметку через `…`, а приложение — через область уведомлений.

Интерфейс, README, установка и изображения доступны на девяти языках из списка выше. Выберите язык в настройках, сохраните и перезапустите приложение. Подробные справочники в основном остаются на японском, английском и упрощённом китайском.

## Устранение неполадок

CLI: проверьте запущенный Obsidian, включённый CLI, абсолютный путь и ID хранилища, затем повторите получение папки. Нет заметки дня: проверьте основной Daily notes и сегодняшний файл; настройки других плагинов не определяются. Предупреждение Tasks: обновите плагин в нужном хранилище и обновите связанные данные. Конфликт записи: сохраните черновик и перечитайте файл. Ошибки Google: проверьте API, тестовых пользователей и разрешения по английскому руководству.

## Обновление, данные и удаление

Для обновления сохраните правки, завершите приложение через область уведомлений, распакуйте новый ZIP в другую папку и запустите `Install.cmd`. Заметки, настройки и копии хранятся отдельно от программы. Если в настройках v0.0.6 или старше нет выбора CLI, теперь CLI включается: для локального режима отключите и сохраните; файлы автоматически не переносятся. Свои шаблоны дат v0.0.1 может потребоваться исправить.

| Данные | Расположение |
| --- | --- |
| Программа | %LOCALAPPDATA%/Programs/MarkdownStickyNotes |
| Настройки и учётные данные | %LOCALAPPDATA%/StickyNotes |
| Копии перед записью | %LOCALAPPDATA%/StickyNotes/backups |
| Заметки | Выбранное хранилище/папка |

Для удаления завершите приложение, удалите папку установки и ярлык меню «Пуск». Заметки, настройки и резервные копии сохранятся; проверьте их перед отдельным удалением.
