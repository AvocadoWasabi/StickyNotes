# Markdown Sticky Notes

[v0.0.11](https://github.com/AvocadoWasabi/StickyNotes/releases/tag/v0.0.11) · Windows 10 / 11 (x64)

Приложение Windows для отображения и редактирования файлов Markdown в окнах заметок. Поддерживает локальные файлы, заметки Obsidian и отдельные разделы ежедневных заметок. Правки и изменения флажков сохраняются в исходном файле Markdown.

Поддерживает вывод результатов запросов Tasks и Dataview через Obsidian CLI, а также получение событий Google Calendar и задач Google Tasks.

## Системные требования и зависимости

Windows 10 / 11 (x64). .NET входит в ZIP; права администратора не нужны. В новых настройках CLI включён по умолчанию. Для локальных файлов отключите его. Отдельный плагин Sticky Notes для Obsidian не требуется.

| Сценарий | Что требуется | Настройка |
| --- | --- | --- |
| Только Markdown | Это приложение | Отключите Obsidian CLI и выберите локальную папку |
| Заметки Obsidian | Запущенный Obsidian + встроенный CLI | Включите Settings → General → Command line interface и подключите хранилище |
| Ежедневные заметки | CLI + основной плагин Daily notes | Задайте папку/формат даты и создайте сегодняшнюю заметку |
| Запросы Tasks | CLI + плагин Tasks | Включите в нужном хранилище; v0.0.11 нужна стабильная версия 8.2.2+ |
| Запросы Dataview | CLI + Dataview | Включите в нужном хранилище; LIST / TABLE / TASK |
| Google | Аккаунт Google + собственная настройка OAuth | Включите Calendar API / Tasks API, импортируйте JSON OAuth для настольного приложения и авторизуйтесь |

[Obsidian CLI](https://obsidian.md/help/cli) · [Google OAuth (English)](docs/GOOGLE-CALENDAR.en.md#setup)

## Установка и первоначальная настройка

1. Скачайте `StickyNotes-win-x64.zip` из Releases, полностью распакуйте и запустите `Install.cmd`.
2. Откройте Obsidian, включите CLI и оставьте нужное хранилище открытым.
3. В настройках приложения проверьте абсолютный путь к `Obsidian.com` и имя/ID хранилища. Получите папку через CLI, выберите папку заметок и сохраните настройки.
4. В меню `…` создайте/откройте заметку либо подключите раздел или ежедневную заметку.

Настройка локальных файлов, обновление и удаление описаны в [руководстве по установке](docs/INSTALL.ru.md). Функции и настройки соответствуют v0.0.11. Изменения по версиям приведены в [журнале изменений (на английском)](CHANGELOG.md#v0-0-11).

## Возможности

| Возможности | Сценарий |
| --- | --- |
| Markdown | Заголовки, списки, флажки, таблицы, код и ссылки; обычные файлы `.md` |
| Разделы и заметки дня | Отображение и правка части заметки, смена даты и сохранение вчерашней заметки при отсутствии сегодняшней |
| Tasks / Dataview | Результаты запросов, отметки с проверенной привязкой к источнику; сохранение текста запросов |
| Ввод задач | Подсказки слов/дат, продолжение списка через Enter, отступ через Tab, настраиваемое сочетание для флажка |
| Google | `@calendar today`: события и незавершённые задачи с датой; правка названия/описания события после подтверждения |
| Окна | Цвета, размер, масштаб 50–200 %, закрепление, временный передний план и панель задач |
| Управление | Выбор/перенос папки, повторное открытие, просмотр файлов, предпросмотр, переименование и удаление |
| Резервные копии и обнаружение конфликтов | Резервирование перед записью и проверка внешних изменений |
| Несколько хранилищ | Ежедневные заметки каждого хранилища, свои имена и выбор хранилища по умолчанию |

## Основные действия

| Действие | Способ |
| --- | --- |
| Редактировать | Щёлкните текст (один/два щелчка настраиваются) или нажмите `Ctrl+E` |
| Сохранить и завершить правку | `Ctrl+S` / `Esc`; первое Esc закрывает открытые подсказки |
| Отметить задачу | Нажмите флажок в режиме чтения |
| Передний план | Закрепление через `○ / ●`; `Alt+Z` выводит все заметки вперёд на 10 секунд |
| Закрыть / выйти | Закройте заметку через `…` / завершите приложение в области уведомлений |

## Область поддержки и ограничения

- Интерфейс, README, установка и изображения доступны на девяти языках из списка выше. Выберите язык в настройках, сохраните и перезапустите приложение. Подробные справочники в основном остаются на японском, английском и упрощённом китайском.
- Для CLI Obsidian должен работать; изменения внутренних API могут повлиять на совместимость.
- Ежедневные заметки не создаются автоматически. Перед первым подключением подготовьте сегодняшнюю заметку.
- Темы Obsidian и все представления плагинов не воспроизводятся. Вместо изображений показывается альтернативный текст. DataviewJS, встроенные выражения и CALENDAR не поддерживаются.
- Google Tasks доступен только для чтения; сроки выполнения получаются только как даты. Время срока, автоматическая синхронизация с задачами Markdown и создание событий Google Calendar не поддерживаются.
- Резервные копии: `%LOCALAPPDATA%/StickyNotes/backups`. При конфликте сохраните черновик, перечитайте файл и повторите попытку.
